# Academic Performance and Study Habits

## Overview

This project analyzes the relationship between students' academic performance and their study habits.

The project uses data mining and data analysis techniques to identify patterns that may affect academic results.

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Google Colab

## Main Features

- Data preprocessing
- Exploratory data analysis
- Analysis of study habits
- Academic performance analysis
- Data visualization
- Results interpretation

## Project Contents

- Dataset analysis
- Data mining implementation
- Visualizations
- Results and documentation

## How to Run

1. Open the project notebook or Python file.
2. Install the required libraries.
3. Load the dataset.
4. Run the analysis and visualization cells.

## Project Type

University Data Mining Project
