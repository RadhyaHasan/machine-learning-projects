# Customer Segmentation Using K-Means

## Overview

This project uses the K-Means clustering algorithm to divide customers into different groups based on selected features.

The goal is to discover customer patterns and support better business decisions.

## Algorithm

- K-Means Clustering

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Google Colab

## Main Features

- Data preprocessing
- Exploratory data analysis
- Customer clustering
- Visualization of customer groups
- Analysis of clustering results

## Project Contents

- K-Means implementation
- Data analysis
- Cluster visualizations
- Results and documentation

## How to Run

1. Open the project notebook or Python file.
2. Install the required libraries.
3. Run the preprocessing code.
4. Apply the K-Means algorithm.
5. View the clustering results.
