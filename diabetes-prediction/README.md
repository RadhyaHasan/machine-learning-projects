# Diabetes Prediction Using Neural Networks

## Overview

This project uses neural networks to predict diabetes based on medical and health-related features.

The model is developed using machine learning and deep learning techniques.

- Keras
- TensorFlow
- Pandas

- Matplotlib
- Google Colab

## Main Features

- Neural network model
- Model training
- Prediction
- Model evaluation

## Project Contents

- Neural network implementation
- Dataset analysis
- Training results
- Presentation and documentation
