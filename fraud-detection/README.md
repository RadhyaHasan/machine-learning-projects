# Fraud Detection Using Machine Learning

## Overview

This project explores fraud detection using machine learning techniques.

The project compares different machine learning models and studies their ability to identify fraudulent transactions.

## Models

- Linear Regression
- Random Forest

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Google Colab

## Project Contents

- Machine learning implementation
- Data analysis
- Model comparison
- Results and evaluation
